# Checksums

One file per depwatch CLI release, `<version>.txt`, copied from that release's `checksums.txt`
(GoReleaser's SHA-256 list). The Action installs only versions listed here, and only when the download
matches. Adding a version is a reviewed change to this repository; there is no "latest".

No release is published yet, so no version is listed. The first release adds `0.1.0.txt`.
